# Description
Utility class to handle `Task` or `CancellationToken`

# Features
## 1.0.0-preview-1.0.0
### Added
+ Convert `ValueTask<T>` to `Task<T>`

+ more easily and safely cancel tasks with `CancellationToken`

## 1.1.0-preview-1.0.0
### # Added
+ Get the result of a `Task<T>` or `Task` instance.

## 1.2.0-preview-1.0.0
### Added Supports
+ Supports .NET 8.0 to .NET 10.0

## 2.0.0
### Major updates
+ Rename project name

+ Rename namespace

+ Make a documentation.
